# Null Strategy

The **Null Strategy** is a private construct used internally within FactoryBot. When ran, it returns `nil` as the result.

## Syntax Methods

- The `FactoryBot.null` method returns `nil`. 
- The `FactoryBot.null_pair` method gives you a pair of `nil` values
- The `FactoryBot.null_list` method gives as many `nil` values as you desire.
