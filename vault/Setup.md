# Setup

The installation and configuration of `factory_bot` can vary depending on which framework you are using, if any, and the test framework in use.

The most common setup will require the following steps:

- [[Adding FactoryBot to Your Gemfile]]
- [[Adding FactoryBot to Your Test Suite]]

Depending on your situation, you may also require the following:

- [[Using FactoryBot With Rails Preloaders and RSpec]]
- [[Using FactoryBot Without Bundler]]

Since installation varies based on code that we do not control, those docs are kept up-to-date in [our wiki](https://github.com/thoughtbot/factory_bot/wiki) which covers more details and considerations for integrating with other software. We encourage you, and the community, to edit the wiki as the frameworks change.
